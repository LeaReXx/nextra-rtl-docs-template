## شروع سریع

می‌توانید این قالب را با کلیک روی دکمه زیر در Vercel دیپلوی کنید:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/LeaReXx/nextra-rtl-docs-template.git)

یا مراحل زیر را دنبال کنید تا مخزن را کلون کرده و به صورت محلی اجرا کنید.

<Steps>
    ### کلون کردن مخزن

    با استفاده از GitHub CLI:
    ```bash
    git clone learex/nextra-docs-starter
    ```

    ### نصب وابستگی‌ها
    ```bash
    npm i
    ```

    ### اجرای سرور توسعه
    ```bash
    npm run dev
    ```

</Steps>
